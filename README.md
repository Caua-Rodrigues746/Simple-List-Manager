# Simple List Manager

A simple Python program that allows the user to add and manage items in a list.

## Version 1

### Features

- Add items in a list
- Allows the user to check the items added to the list

### What I Learned

- Lists
- While loops
- User input
- If statements
- Boolean values
- Break

---

## Version 2

Version 2 expands the original List Manager with item position features.

### Features

- Adds items to the list
- Allows the user to check the position of an item in the list
- Allows the user to check the position of every item in the list
- Allows the user to show items added to the list

### What I Learned

- While loops
- If statements
- Nested if statements
- User input
- Error handling
- Break
- F-strings
- List indexing
- Counter variables
